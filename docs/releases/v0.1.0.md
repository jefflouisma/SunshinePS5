# SunshinePS5 v0.1.0 (MVP)

First public release: a Moonlight-compatible streaming host that runs as a payload on a
jailbroken PS5 (firmware 13.60) and streams to the official Moonlight client.

## Supported

- PS5 firmware 13.60 only (checked at startup), payload loader on TCP 9021.
- Official Moonlight for macOS 6.1.0.
- SDR 1920×1080 H.264 up to 60 fps, console hardware encoder, 1–50 Mbit/s.
- 48 kHz stereo Opus audio.
- One controller.
- Moonlight PIN pairing through the built-in web page on port 8081; pairing and host identity
  persist on the console.
- Private IPv4 networks only.

## Changes since the diagnostic builds

- The host binds to the console's first private IPv4 interface address by default instead of a
  fixed development address, so it starts on any home network without arguments.
- The state directory is created on first run instead of having to exist beforehand.
- The build reports its release version (`sunshineps5-0.1.0`) in the web page and status API.
- Video and audio are paced by the console encoder/audio source instead of a fixed host
  timer that ran slightly slow. The official client now receives 59.97 fps instead of
  59.61 fps, and the frame backlog that grew between host and encoder is gone.
- Moonlight's "host processing latency" now measures processing only, not the wait for the
  next frame.
- Sending a new build no longer creates an extra virtual controller when the previous host had
  no gamepad session (for example after streaming with the official client and no gamepad).
- Repeated sessions on a host started by takeover no longer delete the shared virtual
  controller after the fourth session.
- A session that fails cleanup or is abandoned before PLAY no longer blocks later sessions;
  cleanup is retried and abandoned sessions are reclaimed after 30 s or on the next launch.
- `/resume` from Moonlight now sets up a stream like `/launch`.
- Host error paths stop the stream through the normal teardown instead of freeing state still
  used by streaming threads; a single failed web request or controller report no longer stops
  the host or the stream; failed connection setup no longer leaks sockets.
- `send-to-ps5.sh` sends the payload and shows its log; `scripts/package-release.sh` builds this
  archive.

## Known limitations

- No HDR, no multiple controllers, no rumble/motion/touchpad, no keyboard/mouse forwarding.
- Only the system UI and one game title were validated.
- Capture protection cannot be read on this firmware; the host assumes content is capturable.
- On first use the console may ask "Who's using this controller?" for the virtual pad; press
  Cross from Moonlight to pick your user.
- Keep the host running between sessions. Killing it while a game runs can raise a
  controller-disconnected notice; killing the original controller holder has crashed the console
  in testing. Each host that originally created the controller stays resident (about 16 MiB)
  after a newer build takes over; reboot the console to start from a clean state.
- Other official Moonlight clients (Apple TV, iOS, Android, Windows, Linux) are untested.
